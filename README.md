# Who's Freya?

Charity DNA breed-bet landing page for Freya.

**Live:** https://k04l.github.io/freya-bet/

## Setup
- **[SETUP-GOOGLE-FORM.md](./SETUP-GOOGLE-FORM.md)** — create the Form, get `entry.` IDs, paste into `CONFIG`
- [`create-form.gs`](./create-form.gs) — Apps Script that auto-creates the form + prints IDs
- Venmo / PayPal pledge buttons are already on the page

## Scoring
Sum of `min(guessed%, DNA%)` for matching breeds. Highest wins. Pot → Charity TBD.
