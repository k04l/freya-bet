# Who's Freya?

Charity DNA breed-bet landing page for Freya.

**Live (once Pages is on):** https://k04l.github.io/freya-bet/

## What's on the page
- Meet Freya gallery (photos embedded for GitHub Pages)
- Top-3 breed + % bets (Google Form CONFIG — see SETUP.md)
- Venmo (@Coltan) + PayPal pledge buttons & QR codes
- Scoring: sum of min(guessed%, DNA%) for matching breeds

## Local files (box)
- `index.html` — relative asset paths (use with `/assets`)
- `index.gh.html` — self-contained embed used as `index.html` on GitHub
- `assets/` — optimized webp/jpg Freya photos + payment QRs
- `SETUP.md` — Google Form wiring

## Enable GitHub Pages
Repo → **Settings → Pages → Source: GitHub Actions** (workflow already present) or Deploy from branch `main` / root.
