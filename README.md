# Who's Freya?

Charity DNA breed-bet landing page for Freya.

**Live (once Pages is on):** https://k04l.github.io/freya-bet/

## Files
- `index.html` — self-contained landing page (form + local board + optional Google Form/Sheet wiring)
- `SETUP.md` — 2-minute Google Form + CONFIG wiring
- `make_qr.py` — regenerate themed QR after the URL is final
- Local artifacts (not always in git): `freya-qr.png`, `preview.png`

## Enable GitHub Pages
Repo → **Settings → Pages → Build and deployment → Source: Deploy from a branch** → `main` / `/ (root)` → Save.
